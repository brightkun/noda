Замыкание — функция, которая помнит переменные из места, где была создана, даже после выхода из внешней функции.

```js
function counter() {
  let count = 0;
  return () => ++count;
}
const next = counter();
next(); // 1
next(); // 2
```

`count` недоступна снаружи, но живёт, пока жива внутренняя функция. Так делают приватное состояние.

Классическая ловушка с `var` в цикле:

```js
for (var i = 0; i < 3; i++) setTimeout(() => console.log(i)); // 3 3 3
for (let i = 0; i < 3; i++) setTimeout(() => console.log(i)); // 0 1 2
```

`let` создаёт новую переменную на каждую итерацию. Про порядок выполнения таймеров см. [[Event loop]].

В React замыкания дают «устаревшие» значения в обработчиках и эффектах, см. [[React hooks]].

Частая ошибка: ждать, что `var` в цикле захватит значение на каждой итерации.
