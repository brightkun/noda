JavaScript выполняет код в одном потоке. Event loop решает, что запускать дальше.

Порядок:
1. Синхронный код в стеке вызовов.
2. Все микрозадачи: `Promise.then`, `await`, `queueMicrotask`.
3. Одна макрозадача: `setTimeout`, события, I/O. Потом снова микрозадачи.

```js
console.log("1");
setTimeout(() => console.log("2"), 0);
Promise.resolve().then(() => console.log("3"));
console.log("4");
// 1 4 3 2
```

`setTimeout(fn, 0)` не значит «сейчас»: колбэк пойдёт в очередь макрозадач после текущего кода и микрозадач.

Тяжёлый синхронный цикл блокирует всё: интерфейс замирает. Это важно и в браузере, и в Node.js.

Связано с [[Замыкания]] (колбэки помнят окружение) и [[React Query]] (запросы асинхронны).

Частая ошибка: думать, что `await` блокирует поток. Он только приостанавливает эту функцию.
