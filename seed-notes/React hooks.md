Хуки — функции, которые дают функциональным компонентам состояние и побочные эффекты. Вызывать их можно только на верхнем уровне компонента, не в условиях и циклах.

- `useState`: локальное состояние. `const [n, setN] = useState(0)`
- `useEffect`: побочные эффекты после рендера, зависимости в массиве
- `useRef`: значение, которое переживает рендеры и не вызывает перерисовку
- `useMemo` / `useCallback`: кэш значения или функции, нужен не везде

```tsx
useEffect(() => {
  const id = setInterval(() => setN((n) => n + 1), 1000);
  return () => clearInterval(id); // очистка
}, []);
```

Форма `setN((n) => n + 1)` берёт актуальное значение. Иначе сработает [[Замыкания]] со старым `n`.

Данные с сервера лучше брать через [[React Query]], а не писать свой `useEffect` с `fetch`. Типизация состояния: `useState<User | null>(null)`, см. [[Generics]].

Частая ошибка: забыть зависимость в `useEffect` или сделать бесконечный цикл, обновляя состояние в эффекте без зависимостей.
