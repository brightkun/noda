HTTP — протокол, по которому браузер общается с сервером. Запрос: метод, путь, заголовки, тело. Ответ: статус-код, заголовки, тело.

Методы: GET читает, POST создаёт, PUT заменяет, PATCH меняет часть, DELETE удаляет. GET и PUT идемпотентны (повтор даёт тот же результат), POST нет.

Коды ответа:
- 2xx успех: 200, 201 (создано), 204 (нет тела)
- 3xx перенаправление
- 4xx ошибка клиента: 400, 401, 403, 404, 409
- 5xx ошибка сервера: 500, 502

HTTP не хранит состояние между запросами, поэтому вход держат через [[JWT]] или cookie. Поверх HTTP строят [[REST API]]. Запросы с клиента делает [[React Query]] через fetch или axios.

Частая ошибка: путать 401 (не авторизован) и 403 (авторизован, но нельзя).
