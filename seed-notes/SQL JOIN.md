JOIN соединяет строки двух таблиц по условию. INNER JOIN оставляет только совпавшие пары. LEFT JOIN оставляет все строки левой таблицы, а у несовпавших справа будут NULL.

```sql
select n.title, t.name
from notes n
left join note_tags nt on nt.note_id = n.id
left join tags t on t.id = nt.tag_id;
```

Связь многие-ко-многим (заметки и теги) всегда идёт через промежуточную таблицу. Чтобы собрать теги заметки в один массив, используют `array_agg` и `group by`.

Условие соединения берут из внешнего ключа, а на такие столбцы полезно поставить индекс. Эти запросы вызываются из сервисов [[REST API]].

Частая ошибка: условие по правой таблице в `where` превращает LEFT JOIN в INNER, такое условие надо писать в `on`.
