REST — стиль API, где ресурсы адресуются URL, а действия задаются методами [[HTTP]]. `/notes` это коллекция, `/notes/5` один ресурс.

- GET /notes: список
- POST /notes: создать (ответ 201)
- PUT /notes/5: заменить
- DELETE /notes/5: удалить (ответ 204)

Правила: в URL существительные, а не глаголы; статус-код отражает результат; ошибки возвращаются в одном формате, например `{ message }`. Входные данные проверяют на сервере схемой zod и не доверяют клиенту.

В Express это цепочка route → controller → service, подробнее про промежуточные слои в [[Express middleware]]. Данные лежат в базе, запросы к ней описаны в [[SQL JOIN]].

Частая ошибка: возвращать 200 с текстом ошибки в теле.
